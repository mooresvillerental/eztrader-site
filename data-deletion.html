V73 Data Deletion

Updated: September 12, 2026

V73 currently uses a private installation identity instead of a username-and-password account. Each supported app installation may have separate backend records, including a normal installation and a copy installed in Secure Folder, a work profile, another device profile, or another supported device.

Do not send sensitive credentials or private tokens.

Never include a brokerage password, exchange password, API key, recovery code, seed phrase, bank login credential, raw V73 installation credential, Expo push token, or other trading-platform login information in a deletion request.

How to Request Deletion

  1. Email support@v73technologies.com.
  2. Use the subject line: V73 Data Deletion Request.
  3. Open V73 Settings and include the Installation Support Code shown by the app, when available.
  4. If the support code is unavailable, include the device type, whether the app is installed normally or in Secure Folder or another profile, and a brief description that may help identify the installation.
  5. State clearly that you want installation-related V73 backend data deleted.

Before Uninstalling or Clearing App Storage

When practical, submit the deletion request before uninstalling V73 or clearing its storage. Those actions may remove the locally stored installation identity and support code needed to locate installation-specific backend records.

What May Be Deleted

Depending on what exists for the installation, deletion may include installation-scoped portfolio/session information, user-reported Record-a-Trade history, confirmation and SKIP/deny decision records, push-notification identifiers, settings, alert state, diagnostics, integrity/security records that are not required to be retained, and related backend records.

What May Be Retained

Limited records may be retained when reasonably required for security, legal obligations, fraud prevention, dispute resolution, accounting, backup integrity, system reliability, or other legitimate business purposes. Records retained for those purposes are not kept merely to continue normal deleted app functionality.

Effect on App Functionality

Deleting installation-related backend data may remove alerts, saved settings, tracked portfolio/history, diagnostics, and other installation-scoped app state. A later installation may be treated as a new installation with a new private identity.
